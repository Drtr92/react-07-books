# React-07-books

- "/" <=  검색화면 (첫 페이지)

- "/search" <=  목록 화면 <= 사용자가 입력한 값이 필요
  - 쿼리 스트링을 통해 제공 받아야 됨

- "/detail" <=  상세 화면 <= 프로그램 상 제공된 책 ID가 필요
  - 경로에 동적 라우팅을 통해 제공 받아야 됨
    (물론, 쿼리스트링으로 받아도 됨)

## Remind
http://localhost:5173/search

http    <=  프로토콜
localhost   <=  호스트(도메인 or IP)
5173    <=  포트  (통신을 주고받기 위해 논리적인 도로)

/search    <=  경로
    /search 만 들어와도 뜸
    /search?a=10
    /search?keyword=
    /search?keyword=한글  <= 마찬가지로 뜸

/* 
    Search 이 컴포넌트는 사용자가 요청한 검색 결과를 보여주기 위해서 존재
    백엔드에게 데이터를 받아와서 화면에 출력하는 일
    사용자가 요청한 키워드를 알아야 됨

    요청을 한다는건, 백엔드의 자원을 소비
                 => 수천만개의 데이터 중, 요청에서 원하는 내용만 응답
                    데이터베이스에서 SELECT를 통해 원하는 정보만 검색해야함
                    => 컴퓨터가 일을 한다는 것 => 리소스 소비
*/

/product/상품번호   <=  경로 상에 존재하는 값을 동적 라우팅
                       동적 라우팅을 통해 react-router가 갖게된 값을 꺼내오는건
                       useParams() 

쿼리스트링(queryString) : 보통적으로 사용자가 인풋에 쳐서 전달한 내용
                         페이지를 띄우기 위해 필요한 정보
                         경로 뒤에 "?"로 구분짓고, 여러개를 연결할 떄에는 "&"로 연결 표현함
                         key = value
